Transparent by design.

What our beta does, which assumptions it uses, and where you should not rely on its results.

Comparison methodology

Peer selection. Interventional study type, same phase, shared exact condition label, and study start dates within six years of the target where dates exist. These are practical heuristics, not validated therapeutic-area classifications.

Measures. Counts of registered primary, secondary, and other outcome measures, approximate eligibility text items, arm groups, registered locations, and distinct countries. Outcome-measure count is not the same as number of scientific endpoints. Location count is not a reliable measure of protocol burden by itself.

Percentiles. Midrank: (count below target + 0.5 × count equal to target) / total × 100. Show small-cohort warning below 20 peers.

Live API sampling. The beta retrieves up to 500 candidate registry records for the selected condition, filters locally, and does not guarantee an exhaustive cohort. Percentiles can change when API result ordering or sample size changes. Do not use for consequential decisions.

Historical trends. Synthetic mode calculates the median of observed/phase-and-condition-matched peer median outcome-count ratios in three-year start-date blocks, requiring 5 references for each study. The metric is not an assessment of sponsor quality.

Intended use. Research and discussion. No clinical, medical, regulatory, or financial decisions should rely on this unvalidated prototype.

Sources and reproducibility

Live data: ClinicalTrials.gov API v2. Synthetic data generated with a fixed random seed and explicit synthetic IDs. Method implementations: engine.py and demo_data.py. Automated tests: tests/test_engine.py.
